2.3 Alfa (prawo potęgowe)

-   Do prędkości na piaście alfa nie jest potrzebna — bierzemy height ==
    150.

-   Do FLORIS potrzebna jako flow_field.wind_shear (rozkład prędkości na
    wirniku, łopaty ok. 30–270 m). Dziś kod jej nie ustawia → FLORIS
    bierze domyślne 0,12 (sprawdzone w default_inputs.yaml FLORIS
    4.6.4). farm_model.py nadpisuje tylko reference_wind_height = 150.

-   Plan: α z dopasowania ln(ws) do ln(z) na profilu 50–300 m dla
    każdego kroku; do FLORIS jedna liczba (średnia lub mediana). Wartość
    α dla danych — jeszcze niepoliczona.

-   Gdyby była potrzebna inna wysokość (np. 180 m): lokalna α =
    ln(U200/U150)/ln(200/150), U180 = U150·(180/150)^α. Interpolować
    składowe u, v; kierunek liczyć na końcu.

-   Nie mylić z „alpha (deflection)” = 0,58 w modelu GCH
    (05_advanced_floris.py) — to parametr śladu.

3.3 Hybryda GA → SLSQP i seedy

-   Ustalone na kick-off 26.10 (M2, 18.12.2026): benchmark GA, SLSQP, GA
    → SLSQP na pełnej róży, 5 seedów każdy, ten sam budżet ewaluacji.
    Tabela: zysk AEP, czas, rozrzut między seedami, czy wynik spełnia
    ograniczenia.

-   Jeśli 107 turbin za drogie: benchmark na podzbiorze, wynik
    weryfikowany na róży 10° × 2 m/s.

-   Hybryda nie jest zaimplementowana. Szczegóły (podział budżetu
    GA/SLSQP, kryterium przejścia): nie ustalono.

-   AHGO (CMA-ES na ~8 parametrach geometrii → GA → SLSQP) był pomysłem
    z kwietnia/maja; w majowej prezentacji zastąpiony ogólnym „hybrid
    approach / multi-stage pipeline”. Nie jest zobowiązaniem.

6.4 Pułapki środowiska

-   Po zmianie w src/ usunąć src/__pycache__/ i zrestartować kernel.

-   RandomSearch i ParFlorisModel wieszają się w Jupyterze na Windows
    (multiprocessing) — uruchamiać ze skryptu z __main__.

-   Zgodność modeli: Jensen + jimenez + crespo_hernandez; TurbOPark
    wymaga deflection = none; empirical_gauss wymaga
    wake_induced_mixing; flagi GCH wyłączyć dla innych modeli.

-   disable_turbines z WindRose pokazuje 0% strat — obejście: derating
    do 0 MW.

-   Jeśli site-packages to symlink do dist-packages, FLORIS zgłasza
    „iea_15MW exists in both the internal and external turbine library”
    — uruchamiać z PYTHONPATH=…/dist-packages.

import sys, logging, numpy as np, time, warnings

warnings.filterwarnings("ignore")

sys.path.insert(0, sys.argv[1]); logging.disable(logging.WARNING)

from scipy.spatial.distance import pdist

from floris import TimeSeries

from src.farm_model import FarmModel

from src.wind_data import WindDataLoader

from src.algorithms import ALGORITHMS, bounds_from_layout

from src.algorithms.base import random_feasible_layout, is_feasible

D=240.

def mk(sp, wind):

f=FarmModel("gch","iea_15MW"); f.set_layout_grid(3,3,sp);
f.set_wind_data(wind); return f

narrow = TimeSeries(wind_directions=np.array([270.]),
wind_speeds=np.array([9.]), turbulence_intensities=np.array([.06]))

L=WindDataLoader(); L.generate_mock_data();
rose=L.to_wind_rose(ws_min=0, ws_max=36)

for sp in (7.0,4.0):

for key in ("scipy","genetic"):

f=mk(sp,narrow); b=bounds_from_layout(f.layout_x,f.layout_y,3*D); md=3*D

r=ALGORITHMS[key]().run(f,b,md,100,seed=42)

dmin=pdist(np.column_stack([r.final_x,r.final_y])).min()/D

# re-evaluate final layout on full rose vs initial

g=mk(sp,rose); g.run(); a0=g.get_aep_gwh();
g.set_layout_custom(r.final_x,r.final_y); g.run(); a1=g.get_aep_gwh()

print(f"start {sp}D {key:8s} narrow:
{r.initial_aep:.1f}->{r.final_aep:.1f} ({r.improvement_pct:+.1f}%)
t={r.elapsed_s:.1f}s evals={r.n_evaluations} | minDist={dmin:.2f}D
feasible={is_feasible(r.final_x,r.final_y,b,md)} | FULL ROSE:
{a0:.1f}->{a1:.1f} ({100*(a1/a0-1):+.2f}%)")

# random_feasible_layout diversity for 107 turbines
